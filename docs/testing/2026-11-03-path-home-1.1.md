## Practical limits

The Live Activity uses local ActivityKit updates. It displays the prediction's
time and becomes stale after two minutes; it cannot fetch new predictions while
the app is suspended. Continuous server-driven updates would require a push
service. Widget reload timing remains under iOS control.

Background location following is optional and must be enabled in Settings with
Always permission. Geofence delivery and travel accuracy have not been field
tested on an actual trip. Live-feed and MapKit integration tests require network
availability. iOS 17 is the deployment floor; the installed older simulator used
for compatibility was iOS 18.2.

The original Xcode project/scheme edits and Scriptable folder were preserved.
Source changes are uncommitted on `codex/commute-experience`; no remote push or
kiosk deployment was performed.
